# WebGL Playground

Браузерный прототип редактора материалов на Babylon.js и WebGL 2.

## Запуск

Требуются Node.js и npm. Выполните `npm install`, затем `npx vite` для разработки или `npm run build` для статической сборки в `dist/`.

## Возможности прототипа

- Прямоугольник с настраиваемой толщиной и материалом торцов; отдельные поверхности спереди и сзади.
- Процедурная бумага, старение, край, след чашки, влажное пятно, импорт одного изображения на каждую сторону и параметры материала.
- Сохранение и открытие проекта JSON с вложенными изображениями, экспорт PNG выбранной лицевой или обратной стороны.
- Скругление углов, рваные края и смятость изменяют геометрию обеих сторон и торцов; параметры сохраняются в проекте.
- Единое меню эффектов, несколько слоёв складок, следов чашек, влажных пятен и групп чернил; настройка рваного и затемнённого края.
- Прозрачность бумаги и настраиваемое просвечивание эффектов с обратной стороны.
- Правая кнопка вращает камеру; Ctrl + правая вращает объект по X/Y, Ctrl + Shift + правая — по Z. Есть сброс поворота объекта.

## Ограничения

Это первая версия редактора, а не полный SDK: произвольные шейдеры и граф узлов, несколько независимых импортируемых слоёв на сторону, маски, настройка UV, экспорт normal/roughness и текстур торцов, undo/redo, автосохранение и импорт сторонней normal map пока не реализованы. Поверхностные эффекты генерируются на 2D-холсте и применяются как текстура Babylon.js; форма и смятость задаются геометрией и не входят в экспорт PNG. Шероховатость поверхности задаётся параметром roughness PBRMaterial; её видимость зависит от освещения. Прозрачность и просвечивание эффектов являются визуальным приближением.


План генерации и экспорта GPU-шейдеров описан в [docs/shader-generation.md](docs/shader-generation.md).
